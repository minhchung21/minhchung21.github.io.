## 使用技術

HTML / CSS / JavaScript（フレームワークなしの静的サイト）、GitHub Pages で公開しています。
スマートフォンでも見られるレスポンシブデザインです。

## 構成

```
.
├── index.html        メインページ
├── css/style.css     デザイン・レスポンシブ対応
├── js/script.js      メニュー、ページ上部へ戻るボタン、表示アニメーション
└── assets/           制作物のスクリーンショット
```

## ローカルで確認する

`index.html` をブラウザで開くか、VS Code の Live Server で表示します。

## 更新して公開する

ファイルを編集したあと、次のコマンドを実行します。

```
git add -A
git commit -m "更新内容"
git push
```

`push` すると GitHub Pages が自動で再公開し、1〜2分ほどでサイトに反映されます。
