# NGUYEN CONG MINH CHUNG — Portfolio

## Structure
- `index.html` — main portfolio
- `css/style.css` — design and responsive layout
- `js/script.js` — menu, scroll-to-top and reveal animation

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a repository (e.g. `minhchung21.github.io` or `portfolio`) and push this folder.
2. On GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
3. Put the published URL on your 履歴書 / 職務経歴書.
